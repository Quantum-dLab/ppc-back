# PPC Backend

NestJS backend for PPC, managed with pnpm.

## Setup

```bash
pnpm install
pnpm prisma:generate
```

## Development

```bash
pnpm start:dev
```

## Build And Run

```bash
pnpm build
pnpm start:prod
```

## Tests

```bash
pnpm test
pnpm test:e2e
pnpm test:cov
```

## Prisma

```bash
pnpm prisma:generate
pnpm prisma:migrate
pnpm prisma:deploy
```
